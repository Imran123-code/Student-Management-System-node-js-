# Student Management System

A simple **Student Management System** built using Node.js and core Node.js modules. This project allows users to manage student records through basic CRUD (Create, Read, Update, Delete) operations.

## 🚀 Features

- Add new student records
- View all registered students
- Update existing student details
- Delete student records
- Store student data in a JSON file
- Handle HTTP requests and responses
- Dynamic page routing
- Reusable Header and Footer components

## 🛠️ Technologies Used

- **Node.js** – Backend development
- **HTML5** – Page structure
- **CSS3** – Basic styling
- **JavaScript** – Application logic
- **JSON** – Data storage

## ⚙️ Installation & Setup

1. Clone the repository:

```bash
git clone https://github.com/Imran123-code/Student-Management-System-node-js-.git
```

2. Navigate to the project directory:

```bash
cd Student-Management-System-node-js-
```

3. Run the application:

```bash
node app.js
```

4. Open your browser and visit:

```text
http://localhost:9100
```
